# Libya Charity Platform

Libya Charity (ليبيا الخيرية) is a mobile-first charity platform focused on verified humanitarian cases inside Libya.

## Current scope
- Flutter mobile app frontend first
- Arabic-first and RTL
- Multi-organization charity platform
- Donor flows, campaigns, zakat, sadaqah, sponsorships
- Family case submission with later verification workflow
- Mock data first, backend later

## Repo structure
- `apps/mobile` → Flutter mobile application
- `backend` → future backend services
- `docs` → future product and technical docs

## Current phase
Frontend foundation build with mock data and reusable UI structure.
